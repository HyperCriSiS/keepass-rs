# Repository instructions

- Start with [current work](docs/engineering/CURRENT-WORK.md) and [README](README.md).
- The canonical integration branch is `master`; retain upstream compatibility and unmerged changes. Do not rename or merge long-lived branches as part of a documentation change.
- Review current open PRs and applicable tests before marking work completed. Do not publish releases or change user data on the basis of a documentation handoff.
